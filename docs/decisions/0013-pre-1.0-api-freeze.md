# ADR 0013 — Pre-1.0 public API freeze (private repo)

Date: 2026-09-06  
Status: Accepted  
Context: Track H — stabilize surface before any public/npm release.

## Decision

While the repository stays **private**, treat the following as the freeze candidates for a future 1.0:

### Keep stable

- `createAgent`, `defineTool`, `asAgentTool`
- `AgentRun` as the success value; failures throw with optional `error.agentRun`
- Standard Schema for tools + structured output
- `runWithDeadline`, AbortSignal cooperative cancel, nested signal (ADR 0009 / 0010)
- `parentRunId` / `context.agentRunId` causality (ADR 0011)
- Thin hooks/guards — no policy engines in core
- Optional packages remain optional (`openai`, `rag`, `nestjs`, `migrate`, …)

### Removed before freeze evidence

- `AgentRunResult` alias (use `AgentRun`)
- Deprecated migrate helpers `toMastraTool` / `toLangChainTool` (use `*ToolConfig`)

### Keep with legacy note (postpone removal)

- `withTimeout` — prefer `runWithDeadline`; keep until no callers remain
- `AgentLike.run` loose index signature — postpone tighten until remote agents stabilize

### Publish-ready packaging

- Package `exports.types` / `types` point at `dist/index.d.ts` (not `src/`)
- Packages remain `"private": true` until an explicit owner decision to publish

## Rejected

- Inventing workflow/policy engines in core
- Making the repository public or running `npm publish` as part of this track
- Expanding core to absorb Velum Grid domain logic

## Consequences

Examples and evals must keep compiling against the freeze. First public packages: `@agentstride/core@0.1.0` and `@agentstride/openai@0.1.0`.
